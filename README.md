**MoBro Essential Hardware Monitor Plugin**

This plugin provides a standardized set of essential hardware metrics that work across virtually any
hardware configuration.  
Reads metrics either directly from Windows APIs or uses
the [LibreHardwareMonitorLib](https://www.nuget.org/packages/LibreHardwareMonitorLib/).
